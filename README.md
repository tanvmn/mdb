### Introduction:
This is a JSON REST service for movies information management.\
Visit this URL to check service's health: https://demo-tvmn.work.gd/v1/health.

[Click for User Manual for this JSON REST service](https://drive.google.com/file/d/11OdPqXgSx2yKRRvrnbvLTgjp1t0QyLcb/view?usp=sharing)

Service’s REST API:
```text
GET /v1/health

GET /v1/movies
POST /v1/movies
GET /v1/movies/{id}
PATCH /v1/movies/{id}
DELETE /v1/movies/{id}

POST /v1/users
PUT /v1/users/activated _// disabled due to cloud's vm blocking any SMTP communication_

POST /v1/tokens/authen
```
